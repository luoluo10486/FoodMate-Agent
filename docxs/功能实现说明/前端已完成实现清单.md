## 4. G1 前端基础设施

### 4.1 TypeScript/Vite 路径别名

- `foodmate-ui/tsconfig.json` 和 `foodmate-ui/vite.config.ts` 统一配置 `@/*` 指向 `src/*`。
- 页面、组件和服务使用同一别名规则，避免 Vite 能解析但 TypeScript 无法检查的分裂配置。
- 该边界已通过 `npm run typecheck` 和 `npm run build`。

### 4.2 Tailwind、shadcn/ui 与 FoodMate 语义 Token

- `src/styles/tokens.css` 建立 FoodMate 颜色、字体、间距、圆角、边框和状态变量，并作为 shadcn 组件和页面样式的语义来源。
- Tailwind 已接入 Vite，组件目录位于 `src/components/ui`，基础工具位于 `src/lib/utils.ts`。
- shadcn/ui 只负责可组合控件和可访问行为，工作台、消息流、Agent 轨迹和页面布局仍由 FoodMate 领域组件负责。
- 当前完成的是基础设施可用边界；由于 Arco 仍有存量引用，不能把 G6 依赖清理或“全仓只剩 shadcn”写成已完成。

### 4.3 图标使用边界

- 标准命令图标使用项目统一图标组件和 Lucide，已覆盖发送、停止、搜索、编辑、删除、复制、下载、刷新、展开等操作。
- 页面不直接写入 iconfont 字码、Unicode 图标或未经登记的内联矢量。
- 领域图标只有在资源来源、授权、字形类名和适配背景确认后才允许进入 iconfont 封装。
- 当前 iconfont 实体字体包和最终资源注册仍未确认，因此本阶段只关闭标准命令图标边界，iconfont 资源登记保持 `BLOCKED`。

## 9. 状态、权限与敏感数据边界

### 9.1 已完成的状态处理

- 页面已覆盖默认、加载、空、错误、提交中、成功、失败和必要的过期状态。
- Agent 交互已覆盖运行中、追问、确认、取消、SSE 重连、预算提示、预算耗尽和安全降级等前端展示语义。
- 管理写操作已覆盖 operator 无权限、admin 二次确认、提交中、成功和失败；失败显示稳定错误码和请求标识。
- real 模式无法取得后端数据时显示空态、错误态或 `-`，不把 mock 样例伪装成真实数据。

### 9.2 当前已实现的权限边界

- 顶部管理入口仅对 `admin/operator` 展示；普通用户不应进入管理后台。
- operator 可查看管理数据，但管理写操作保持禁用或进入无权限状态。
- admin/superadmin 可执行已接入的高风险操作，并必须经过确认和审计状态机。
- 用户侧会话、消息和 AgentRun 继续依赖服务端当前用户归属校验；前端不自行扩大数据可见范围。

这里记录的是已经接入的页面行为，不代表普通用户、operator、admin 在所有管理路由、所有真实 API 和并发竞态下的全量权限矩阵已经验收完成。

### 9.3 敏感数据处理

- Tool、SQL 和 Trace 详情只展示脱敏摘要、查询哈希、策略、返回行数和链路元数据。
- 不在页面返回数据库凭据、访问令牌、密码、令牌哈希或隐藏推理内容。
- ID 复制只复制页面允许展示的公开标识，不绕过后端权限读取完整对象。

## 10. 数据库与外部依赖边界
