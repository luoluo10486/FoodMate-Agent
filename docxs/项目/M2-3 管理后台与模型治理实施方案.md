## 1. 目标

将管理后台 real 模式从混合 mock/有限查询升级为真实、分页、受权限控制的运营入口，并完成模型路由、预算、配额、价格版本和用量汇总治理。fixture 模式继续服务设计预览，但不得成为真实模式的降级数据源。

## 2. 角色矩阵

| 能力 | operator | admin | superadmin |
|---|---:|---:|---:|
| 查看脱敏运行/用量/审计 | 是 | 是 | 是 |
| 查看知识任务进度 | 是 | 是 | 是 |
| 用户状态、知识文档、失败任务 | 否 | 是 | 是 |
| 普通工具启停 | 否 | 是 | 是 |
| 高风险工具启停 | 否 | 否 | 是 |
| 模型路由、价格、全局预算/配额 | 否 | 否 | 是 |
| 密钥明文读取/编辑/导出 | 否 | 否 | 否 |

前端根据角色调整可见命令，Java 每个接口仍必须独立鉴权。高危动作必须二次确认、revision/幂等校验和统一审计。

## 3. 管理查询 API

为以下资源提供统一分页、筛选、排序和稳定 DTO：

- 用户和认证安全摘要。
- AgentRun、ToolCall、SQL audit 和运行错误。
- Tool Registry 与版本状态。
- 知识文档、导入批次和索引错误。
- operation audits 与软删除资源。
- 模型调用用量、成本和状态。

分页使用稳定 cursor 或 page/size + 确定排序，单页设置上限。所有查询先在 SQL 层裁剪字段，不先读取敏感内容再由前端隐藏。

## 4. 管理写操作

用户禁用/启用、会话撤销、工具启停、知识发布/下线/恢复/删除、失败任务重试、软删除资源恢复和模型治理变更都必须：

1. 由 application 用例编排。
2. 校验角色、资源状态和 revision。
3. 接收幂等键并防重复副作用。
4. 高危操作要求明确确认摘要。
5. 业务状态与成功审计同事务；失败使用既有失败审计策略。

## 5. 模型治理数据

复用并扩展现有 provider/model/route/usage 基线，保存：

- provider code、model name、scene、状态和路由优先级。
- 上下文/输出上限、timeout、retry policy 和功能能力。
- 每百万 Token 价格、币种、价格版本和生效时间。
- 单 Run、单用户、单日和全局预算/配额。
- 用量、延迟、成本和错误分类汇总。

Secret 不进入数据库治理表。Runtime 从环境或 Secret 读取 API Key；后台只能显示 `configured=true/false` 和不可逆配置指纹，不显示长度、前后缀或任何可用于恢复密钥的信息。

## 6. 路由与预算语义

- Python ModelRouter 只选择 Java 下发或启动配置允许的 route snapshot。
- route/model/price/budget 版本进入 usage 事实，历史账单不随当前价格变化重算。
- 禁用模型不能接受新请求；已开始调用按原快照完成并记录。
- 预算不足在调用前拒绝，返回稳定错误；当前阶段只做后台阈值提示，不接生产告警平台。
- local-stub 不产生真实供应商成本，但仍记录 deterministic provider 和零成本事实。

## 7. 前端真实模式

`VITE_AGENT_MODE=real` 下：

- 所有表格、详情、状态变更和汇总来自真实 API。
- 请求失败显示错误状态和重试命令，不显示 fixture 数据。
- 分页、筛选条件和选中资源在刷新后保持可解释状态。
- 不在页面中展示 Prompt、完整模型回答、文档原文、对象存储路径、令牌或密钥。
- 高危命令使用统一确认 Dialog，确认文案包含目标、影响和不可自动恢复的部分。

fixture 模式保持现有视觉状态和交互样例；其数据和测试不能作为 M2-3 业务完成证据。

## 8. 审计与导出

- operator 只查看安全摘要。
- admin 可导出自己权限范围内的脱敏运营数据。
- superadmin 可发起系统级脱敏导出，但仍不能导出密钥、Prompt、完整回答和原文。
- 导出任务记录筛选条件、字段集合、发起人、状态和过期时间；当前只实现有界业务导出，不做大规模异步报表性能优化。

当前实现：`POST/GET /api/admin/exports` 和 `POST /api/admin/exports/{id}/download` 提供最多 100 条安全查询摘要的异步 JSON 导出；字段由 application 白名单裁剪，admin 禁止导出用户/删除资源，superadmin 可导出全部安全摘要。下载资格过期或消费后不可重复使用，导出请求、生成失败和下载均写统一操作审计。

## 9. 业务测试

后端覆盖分页/筛选、三级权限、字段脱敏、高危确认、revision、幂等、模型 route/price/budget 版本和用量聚合。前端覆盖 real/fixture 隔离、加载/空态/错误、角色命令和确认 Dialog，并通过 typecheck/build。

不包含后台大数据量性能、告警平台、密钥轮换演练、浏览器矩阵或移动端专项。
